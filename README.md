# TARS project page

Static project page for **TARS: Timestep-Aware Data Scaling for 3D-Free Video Re-Shooting**.

The page is intentionally self-contained: GitHub Pages serves `index.html` from the repository root, with no build step.

## Content to add

- Add the final method figure as `image/overall.png`.
- Put all demonstration media inside `case/`.
- Give each case a web-compatible MP4 (H.264/AAC recommended) and, when available, a same-named WebP poster image.
- Send the final paper URL, code URL, final BibTeX, acknowledgements, and responsible-use contact details for the corresponding page updates.

The current HTML provides twelve featured case slots in four groups: trajectory control, semantic viewpoint control, reverse-angle re-shooting, and perspective switching. Their exact slot names and insertion markup are documented in `case/README.md`.
